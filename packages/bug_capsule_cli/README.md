# bug_capsule_cli

The bugcapsule command line — inspect, replay, verify and manage capsules.

Part of the [BugCapsule Flutter SDK](https://github.com/draz26648/bug_capsule_flutter_sdk) — see the root README for setup and usage.

Since 0.3 it replays capsules from the Flutter, native Android, native iOS and
web SDKs; see [docs/cli-runtimes.md](../../docs/cli-runtimes.md) for
`bugcapsule.json`, prebuilt artifacts and the replay protocol (per-attempt
tokens, stale-report rejection, loopback only).
